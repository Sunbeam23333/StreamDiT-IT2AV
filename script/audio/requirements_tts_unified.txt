# ============================================================================
# WorldModel TTS 统一环境依赖（实用版）
#
# 目标：给 TTS benchmark / 统一脚本提供一套尽量兼容的依赖基线。
#
# 适用范围：
#   - ChatTTS
#   - Spark-TTS
#   - F5-TTS
#   - CosyVoice / CosyVoice2 / CosyVoice3（多数场景可共用，但官方仍推荐单独环境）
#
# 暂不纳入统一环境：
#   - Fish-Speech S2
#     原因：官方 pyproject 绑定 torch==2.8.0，且依赖链明显重于当前其它 TTS；
#     现有项目内旧版 1.5 runner 也已与 vendored repo 脱节，建议单独环境或服务化接入。
#
# 推荐环境：
#   conda activate it2av
#   pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu124
#   pip install -r script/audio/requirements_tts_unified.txt
#
# 如果当前环境里已经装好 torch / torchaudio，可直接执行最后一行。
# 如果要在同一环境中跑 CosyVoice：
#   Linux + CUDA 建议额外安装：
#   pip install onnxruntime-gpu==1.20.1
#
# 说明：
#   1. 本文件偏向“能跑 benchmark”的统一基线，而不是逐仓库一比一复刻官方环境。
#   2. 若某个模型需要官方满血能力（训练/WebUI/服务化），优先使用其 repo 原生 requirements / pyproject。
#   3. ChatTTS 的 `pynini` / `WeTextProcessing` / `nemo_text_processing` 不纳入默认 pip 安装。
#      原因：它们主要用于文本归一化，官方示例也按“可选增强项”处理；其中 `pynini` 常在 Python 3.12+
#      或部分 Linux 环境下退回源码构建并失败。统一 benchmark 不依赖它们。
#   4. 如果你确实要启用 ChatTTS 文本归一化，建议单独执行：
#      conda install -c conda-forge pynini=2.1.5
#      pip install WeTextProcessing nemo_text_processing
# ============================================================================
